#

Fruit Classification Model

A simple image classification model to recognize different types of fruits using Teachable Machine and TensorFlow (Keras), with a Python test script run on Google Colab.

⸻

Features
	•	Train a custom image classification model (Strawberry, Apple, Watermelon, Banana)
	•	Export the model in Keras format
	•	Upload and test images using Python script
	•	Predict fruit class with TensorFlow model

⸻

Technologies Used
	•	Model Training: Teachable Machine by Google
	•	Model Format: TensorFlow (Keras)
	•	Testing Script: Python 3.x
	•	Libraries:
	•	TensorFlow
	•	NumPy
	•	Pillow
	•	Platform: Google Colab

⸻

Installation & Usage

Prerequisites
	•	Python 3.x
	•	Google Colab account (recommended)
	•	Trained model files:
	•	keras_model.h5
	•	labels.txt
	•	Test image (e.g. test.jpg)

⸻

Steps to Run
	1.	Open the Colab notebook (predict.ipynb).
	2.	Upload the following files when prompted:
	•	keras_model.h5
	•	labels.txt
	•	Your test image
	3.	Run all cells in the notebook.
	4.	The predicted fruit class will be displayed in the output.
